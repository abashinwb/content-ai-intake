# Intake logic

## Входные данные

### Блок 1. Задача

| Значение | Обязательность | Зачем нужно |
|---|---|---|
| Заполнить шаблон | Один из трёх вариантов обязателен | Определяет сценарий заполнения недостающих характеристик |
| Проверка ошибок | Один из трёх вариантов обязателен | Определяет сценарий проверки и коррекции значений |
| Шаблон для Figma | Один из трёх вариантов обязателен | Определяет сценарий подготовки данных для инфографики |

Пока задача не выбрана, кнопка `Продолжить` недоступна.

### Блок 2. Excel-файл

| Поле | Обязательность | Проверка |
|---|---|---|
| Excel-файл | Обязательно | Расширение `.xlsx` или `.xls`, размер не более 20 МБ |

Пока валидный файл не выбран, кнопка `Обработать файл` недоступна. Категорию вручную выбирать не нужно: Content AI определяет её по содержимому файла.

## Логика обработки

### Заполнение и проверка ошибок

1. Товар определяется по артикулу, модели, наименованию и загруженному баркоду.
2. Категория определяется автоматически.
3. Артикул, ЕАН, цена и НДС сохраняются в исходном порядке.
4. Корректируются только характеристики товара, которые увидит покупатель.
5. Неподтверждённые значения помечаются в файле и журнале ошибок.

### Шаблон для Figma

1. Система определяет категорию товара.
2. Выделяет характеристики, необходимые для инфографики.
3. Если данных недостаточно, показывает спокойное сообщение и предлагает перейти к `Заполнению шаблона`.
4. После заполнения пользователь возвращается к Figma-ветке без повторной загрузки.

## Проверка полноты

На экране `Проверка` отображаются:

- категория товара;
- имя файла;
- `Заполнено` — зелёный статус;
- `Скорректировано` — жёлтый статус;
- `Требует проверки` — красный статус.

Числа в прототипе учебные и зависят от выбранной задачи.

## Блокирующие условия

- не выбрана задача;
- не выбран файл;
- файл имеет неподдерживаемое расширение;
- файл больше 20 МБ;
- в Figma-ветке не хватает обязательных характеристик.

## Текст состояния «не хватает данных»

Заголовок: `Не все характеристики заполнены`.

Сообщение: `Для четырёх значений не найдено достаточно данных. Сначала дополните исходный файл, а затем вернитесь к созданию шаблона для Figma.`

Действие: `Перейти к заполнению шаблона`.

## Что можно сделать позже

- загрузить новый файл после завершения;
- повторно скачать результат;
- сформировать отдельный Figma-шаблон после заполнения или проверки.
