# Prototype brief

## Сервис

Content AI — intake-портал для обработки товарных Excel-каталогов маркетплейса.

## Пользователь

Контент-менеджер, категорийный менеджер или сотрудник продавца, который работает с товарными карточками и Excel-шаблонами.

## Задача пользователя

Выбрать тип обработки, передать Excel-файл с товарами, увидеть результат проверки полноты и скачать готовый файл без дополнительных объяснений.

## Что пользователь делает в сценарии

1. Выбирает одну задачу: заполнение шаблона, проверка ошибок или подготовка шаблона для Figma.
2. Загружает Excel-файл.
3. Получает автоматически определённую категорию и результаты обработки.
4. Видит, сколько значений заполнено, скорректировано и требует проверки.
5. При необходимости дополняет данные для Figma.
6. Скачивает результат или начинает обработку нового файла.

## Успешное прохождение

Пользователь самостоятельно доходит от выбора задачи до экрана `Скачивание началось`, понимает статус файла и может повторно скачать результат.

## Границы прототипа

Включено:

- один intake-сценарий с тремя вариантами задачи;
- четыре основных экрана: Старт, Загрузка, Проверка, Готово;
- проверка обязательного Excel-файла;
- состояние «не хватает данных»;
- кликабельные переходы, включая возврат через верхнее меню;
- учебные файлы для скачивания.

Не включено:

- реальная передача и обработка Excel на сервере;
- поиск характеристик по внешним источникам;
- авторизация, личный кабинет и история обработок;
- реальное формирование логов ошибок;
- интеграция с Wildberries или Figma;
- хранение конфиденциальных данных.
