# Screen copy

## Общие элементы

- бренд: `Content AI`;
- статус: `Учебное демо`;
- шаги: `Старт`, `Загрузка`, `Проверка`, `Готово`;
- подвал: `Кликабельный прототип · Неделя 5`.

## Экран 1. Старт

Надзаголовок: `Новая обработка`.

Заголовок: `Начало работы`.

Вводный текст: `Укажите задачу, загрузите Excel-файл с товарами и получите готовый результат.`

Карточки задачи:

1. `Заполнить шаблон` — `Полностью заполнит карточки товаров недостающими характеристиками.`
2. `Проверка ошибок` — `Проверит шаблон на наличие ошибок и скорректирует значения.`
3. `Шаблон для Figma` — `Проверит структуру файла и составит файл для создания инфографики.`

Сноска: `Ваши данные остаются конфиденциальными. Загруженные файлы не публикуются и не передаются в открытый доступ.`

Кнопка: `Продолжить`.

## Экран 2. Загрузка

### Ветка «Заполнить шаблон»

Заголовок: `Заполнение шаблона`.

Описание: `Загрузите Excel-файл с товарами. Content AI определит категорию по содержимому файла и заполнит недостающие характеристики карточек товаров.`

### Ветка «Проверка ошибок»

Заголовок: `Проверка шаблона на наличие ошибок`.

Описание: `Загрузите Excel-шаблон с товарами. Content AI определит категорию по содержимому файла, проверит значения и скорректирует обнаруженные ошибки.`

### Ветка «Шаблон для Figma»

Заголовок: `Составление шаблона для Figma`.

Описание: `Загрузите Excel-файл с товарами. Content AI определит категорию и выделит характеристики, необходимые для шаблона инфографики.`

### Загрузка файла

- label: `Excel-файл *`;
- пустое состояние: `Перетащите файл сюда или выберите на компьютере`;
- подсказка: `Поддерживаются .xlsx и .xls до 20 МБ`;
- действие: `Выбрать`;
- учебная альтернатива: `Использовать учебный пример`;
- валидный файл: `Файл загружен`;
- пояснение: `Категория товаров будет определена автоматически по содержимому файла.`;
- ошибка формата: `Выберите файл в формате .xlsx или .xls.`;
- ошибка размера: `Размер файла не должен превышать 20 МБ.`

### Обработка для заполнения и проверки

1. `Автоматическое определение товара` — `Content AI сам определит товар по артикулу, модели, наименованию и загруженному баркоду и заполнит шаблон в соответствии с категорией товара.`
2. `Сохранение технических данных` — `Артикул, ЕАН, цена и НДС останутся в том же порядке, в котором были загружены. Корректировки производятся только в характеристиках товара, которые увидит покупатель на сайте.`
3. `Проверка достоверности` — `Если Content AI не сможет подтвердить информацию, значение будет отмечено в файле и журнале ошибок для последующей перепроверки. Неправильная информация не попадёт на сайт.`

### Обработка для Figma

`Content AI определит категорию товаров и выделит характеристики, необходимые для подготовки шаблона инфографики. Если в файле будут обнаружены ошибки или недостающие данные, система сообщит об этом и предложит варианты заполнения.`

Кнопки: `Назад`, `Обработать файл`.

## Экран 3. Проверка

Заголовок: `Проверка`.

Описание: `Файл обработан. Проверьте результаты и скачайте готовый файл.`

Сводка: `Категория — Смартфоны`, имя загруженного файла.

Статусы:

- зелёный: `Заполнено` — `Характеристики заполнены и подтверждены по надёжным источникам.`;
- жёлтый: `Скорректировано` — `Изменённые значения отражены в журнале ошибок.`;
- красный: `Требует проверки` — `Для этих значений не найдено однозначного подтверждения.`

### Дополнительный Figma-результат после заполнения или проверки

Заголовок: `Подготовить данные для Figma`.

Описание: `Content AI может выделить характеристики товаров и подготовить отдельный шаблон для создания инфографики.`

Кнопка: `Создать шаблон для Figma`.

Успешное состояние: `Шаблон для Figma создан. Категория определена, характеристики для инфографики подготовлены.`

### Figma-ветка

Заголовок блока: `Характеристики для шаблона инфографики`.

Данные: категория `Смартфоны`, `28 товаров`, характеристики `Модель`, `Диагональ экрана`, `Объём памяти`, `Разрешение камеры`, `Ёмкость аккумулятора`, `Цвет`.

Состояние нехватки данных:

- заголовок: `Не все характеристики заполнены`;
- текст: `Для четырёх значений не найдено достаточно данных. Сначала дополните исходный файл, а затем вернитесь к созданию шаблона для Figma.`;
- действие: `Перейти к заполнению шаблона`.

Состояние после заполнения:

- заголовок: `Данных достаточно для создания шаблона`;
- текст: `Недостающие характеристики заполнены. Можно подготовить итоговый файл для Figma.`;
- действие: `Создать шаблон для Figma`.

## Экран 4. Готово

Надзаголовок: `Обработка завершена`.

Заголовок: `Скачивание началось`.

Описание: `Готовый файл должен скачаться автоматически.`

Резервное действие: `Если скачивание не началось, воспользуйтесь ссылкой ниже.`

Новый сценарий: `Обработать другой файл. Вернитесь к началу, чтобы выбрать новую задачу и загрузить другой Excel-файл.`

Кнопка: `Загрузить новый файл`.

## Правила языка

1. Короткие деловые формулировки без внутреннего технического жаргона.
2. Ошибка объясняет, что произошло и как продолжить.
3. Результат каждого действия подтверждается отдельным понятным состоянием.
