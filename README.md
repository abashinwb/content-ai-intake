# Content AI — intake-портал

Кликабельное клиентское демо для домашнего задания недели 5. Сценарий показывает, как клиент выбирает задачу, загружает Excel-каталог, проверяет результат и скачивает готовый файл.

После публикации репозитория `abashinwb/content-ai-intake` адрес сайта будет:

`https://abashinwb.github.io/content-ai-intake/`

## Что находится в архиве

- `index.html`, `styles.css`, `script.js` — автономный сайт без сборки и внешних зависимостей;
- `demo/` — два учебных Excel-файла для имитации скачивания;
- `prototype_brief.md` — цель, пользователь, успех и границы сценария;
- `screen_map.md` — карта экранов и переходов;
- `intake_logic.md` — обязательные данные, проверки и ветвления;
- `screen_copy.md` — тексты всех экранов и состояний;
- `prototype_test_log.md` — три сценарных тестовых прохода и выводы;
- `prototype_handoff.md` — готовое, ограничения и передача в следующие недели;
- `prompt_log.md` — журнал промптов и решений.

## Как опубликовать на GitHub Pages

1. На открытой странице GitHub оставьте имя `content-ai-intake`, видимость `Public`, README — `Off`, `.gitignore` — `No .gitignore`, лицензию — `No license`.
2. Нажмите `Create repository`.
3. Распакуйте ZIP на компьютере.
4. В новом репозитории нажмите `Add file` → `Upload files`.
5. Перетащите в окно GitHub **всё распакованное содержимое**, включая папку `demo`. Файл `index.html` должен лежать в корне репозитория.
6. Нажмите `Commit changes`.
7. Откройте `Settings` → `Pages`.
8. В разделе `Build and deployment` выберите `Deploy from a branch`, ветку `main`, папку `/(root)` и нажмите `Save`.
9. Подождите 1–3 минуты и откройте `https://abashinwb.github.io/content-ai-intake/`.

## Как пройти демо

1. Выберите одну из трёх задач.
2. Нажмите `Продолжить`.
3. Выберите Excel-файл или нажмите `Использовать учебный пример`.
4. Нажмите `Обработать файл`.
5. Проверьте результат. В ветке Figma сначала показано состояние «не хватает данных».
6. Скачайте файл и завершите сценарий.

Прототип не отправляет загруженные файлы на сервер и не обрабатывает их содержимое. Это учебная имитация интерфейса.
