# Prototype test log

## Метод

Задача для каждого прохода: `Представьте, что вам нужно обработать товарный Excel-каталог. Выберите подходящую задачу, пройдите демо до скачивания результата и говорите вслух, если следующий шаг непонятен.`

Подсказки во время прохождения не давались. Проверялись понятность сервиса, обязательность файла, видимость состояния полноты, возврат назад и завершение.

Важно: ниже зафиксированы три самостоятельных сценарных QA-прохода прототипа. Коридорные тесты с тремя внешними участниками ещё не проводились; перед финальной сдачей этот журнал рекомендуется дополнить их наблюдениями.

## Проход 1. Заполнение шаблона

- Маршрут: `Старт → Заполнение шаблона → Проверка → Создать шаблон для Figma → Скачать оба файла → Готово`.
- Результат: путь пройден до конца без тупиков.
- Наблюдение: без выбранной задачи кнопка `Продолжить` заблокирована; без файла заблокирована кнопка `Обработать файл`.
- Наблюдение: после создания Figma-шаблона блок дополняется подтверждением, а не заменяет экран.
- Наблюдение: на финальном экране доступны две резервные ссылки.
- Проблема: критических проблем не обнаружено.
- Приоритет: `P1 — критичных замечаний нет`.

## Проход 2. Проверка ошибок и возврат через верхнее меню

- Маршрут: `Старт → Проверка шаблона на наличие ошибок → Проверка → верхнее меню Загрузка → Проверка → Скачать результат → Готово`.
- Результат: путь пройден до конца; возврат к уже посещённому шагу работает.
- Наблюдение: заголовок экрана меняется в соответствии с выбранной задачей.
- Наблюдение: результаты показаны зелёным, жёлтым и красным статусами.
- Наблюдение: будущие непройденные шаги в меню заблокированы.
- Проблема: длинный заголовок проверки занимает больше места на узком экране, но не мешает прохождению.
- Приоритет: `P2`; перенос строки сохранён адаптивной вёрсткой.

## Проход 3. Figma и состояние «не хватает данных»

- Маршрут: `Старт → Составление шаблона для Figma → Проверка → Не хватает данных → Заполнение шаблона → Проверка → Вернуться к Figma → Создать шаблон → Скачать → Готово`.
- Результат: ветка пройдена до конца без мысленных переходов.
- Наблюдение: система показывает категорию, количество товаров и список выделенных характеристик.
- Наблюдение: предупреждение прямо сообщает, чего не хватает, и предлагает единственное следующее действие.
- Наблюдение: после заполнения повторная загрузка не требуется.
- Проблема: фактического анализа Excel нет; состояние смоделировано.
- Приоритет: `Позже`, потому что реальная обработка не входит в кликабельный прототип.
