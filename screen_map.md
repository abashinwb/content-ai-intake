# Screen map

В прототипе четыре основных экрана. Ветвления реализованы состояниями внутри экранов, поэтому основной путь остаётся коротким.

| Экран | Роль экрана | Что делает пользователь | Что видит после действия | Куда идёт дальше |
|---|---|---|---|---|
| 1. Старт | Объяснить сервис и зафиксировать задачу | Выбирает одну из трёх карточек | Выбранная карточка отмечена, кнопка `Продолжить` активна | Экран 2. Загрузка |
| 2. Загрузка | Получить обязательный Excel-файл и объяснить обработку | Выбирает `.xlsx`/`.xls` или учебный пример | Имя файла, статус готовности, информация об автоматическом определении категории | Экран 3. Проверка |
| 3. Проверка | Показать полноту и результат обработки | Просматривает категорию, зелёный/жёлтый/красный статусы, при необходимости создаёт Figma-шаблон | Готовность файла либо блок `Не все характеристики заполнены` | Экран 4. Готово или ветка заполнения |
| 4. Готово | Подтвердить завершение и дать понятный следующий шаг | Повторно скачивает файл или выбирает `Загрузить новый файл` | Ссылки на результат и возврат к новому сценарию | Экран 1. Старт |

## Ветвления

### Заполнить шаблон

`Старт → Заполнение шаблона → Проверка → [опционально: создать шаблон для Figma] → Готово`

### Проверка ошибок

`Старт → Проверка шаблона на наличие ошибок → Проверка → [опционально: создать шаблон для Figma] → Готово`

### Шаблон для Figma

`Старт → Составление шаблона для Figma → Проверка → Не хватает данных → Заполнение шаблона → Проверка → Вернуться к Figma → Создать шаблон → Готово`

## Навигация

- кнопка `Назад` возвращает на предыдущий экран;
- пройденные шаги в верхнем меню кликабельны;
- непройденные шаги заблокированы;
- линии соединяют маркеры шагов и не перечёркивают подписи.
