# Handoff прототипа Content AI

## Ссылки

**Публичное демо:** https://abashinwb.github.io/content-ai-intake/  
**Репозиторий:** https://github.com/abashinwb/content-ai-intake

## Что показывает прототип

Content AI — кликабельное intake-демо для обработки товарных Excel-шаблонов. Пользователь проходит один короткий сценарий:

1. выбирает задачу;
2. загружает Excel-файл;
3. получает демонстрационную сводку обработки;
4. при необходимости создаёт дополнительный шаблон для Figma;
5. скачивает результат.

В прототипе четыре связанных экрана. Три варианта на стартовом экране являются ветками одного процесса, а не отдельными продуктами.

## Что реализовано

- четыре экрана от выбора задачи до скачивания;
- три варианта обработки с динамическими заголовками и текстами;
- обязательный одиночный выбор задачи;
- загрузка и перетаскивание `.xlsx`/`.xls`;
- проверка формата и ограничения 20 МБ;
- учебный файл для быстрого прохождения;
- автоматическое определение категории в демонстрационном виде;
- зелёный, жёлтый и красный показатели результата;
- отдельная ветка создания шаблона Figma;
- переход Figma → заполнение → возврат в Figma с сохранением файла;
- кликабельные пройденные этапы верхнего меню;
- сохранение данных при возврате назад;
- учебные `.xlsx` для скачивания;
- резервные ссылки повторного скачивания;
- сброс сценария через «Загрузить новый файл»;
- адаптация интерфейса под узкий экран;
- публикация через GitHub Pages.

## Что проверено

Проведены:

- три технических сценарных прохода;
- три ролевых UX-прохода по ролям целевых пользователей: контент-менеджер, специалист по качеству карточек и пользователь ветки Figma.

Ролевые проходы выполнены автором как структурированная симуляция из-за отсутствия независимых респондентов и не выдаются за внешние интервью. Подробности и наблюдения записаны в `prototype_test_log.md`.

По итогам проверки P1-проблем, блокирующих основной сценарий, не найдено. Неблокирующие замечания оставлены как P2/следующая итерация.

## Что имитируется

Прототип не является готовым серверным сервисом. В нём имитируются:

- анализ содержимого Excel;
- определение категории;
- поиск товарных характеристик;
- числа «Заполнено», «Скорректировано» и «Требует проверки»;
- фактическая обработка пользовательского файла.

Скачиваемые файлы — заранее подготовленные учебные примеры. Загруженный пользователем файл не отправляется на сервер.

## Что пока не готово

- серверная обработка и хранение файлов;
- подключение категорийных мануалов;
- реальный журнал ошибок по загруженному каталогу;
- просмотр конкретных исправлений до скачивания;
- авторизация и история обработок;
- независимые коридорные тесты с внешними пользователями.
